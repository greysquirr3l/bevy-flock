## Where to go first

If you have never used it, read [Install](/bevy-flock/start/getting-started/) then
[A crowd in five lines](/bevy-flock/start/first-crowd/). Both are short on purpose.

If you are deciding whether it fits, read [Concepts](/bevy-flock/start/concepts/) and
[Performance](/bevy-flock/reference/performance/) — the numbers there are measurements with the fixture named, not
rounded claims.

If you are already running a crowd and it is not behaving the way you want, the guides are the place:
[Behaviour that varies](/bevy-flock/guides/behaviour/), [Memory and grudges](/bevy-flock/guides/memory/),
[Scaling to a million](/bevy-flock/guides/scaling/).

## What it is not

`bevy-flock` is a simulation library for Bevy, not a full NPC game framework: no renderer, no physics, no networking, no
filesystem adapters. The [coverage page](/bevy-flock/reference/coverage/) is explicit about what is in the crate and what
stays your job, because finding out at integration time is worse than reading it here.
