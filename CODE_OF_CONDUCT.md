# Code of conduct

## The short version

Be decent. Critique code, not people. Assume the person you are replying to is
acting in good faith and has read less of this crate than you have.

## Scope

Issues, pull requests, discussions and any other space this project owns.

## Expected

- Disagree about design with reasons, alternatives and evidence.
- Say "I do not know" when you do not.
- Accept that a maintainer's "no" to a feature is a decision, not an insult.
- Keep review comments about the code in front of you.

## Not acceptable

- Harassment, insults, or sustained disruption.
- Discrimination on the basis of who someone is.
- Publishing someone's private information.
- Dismissing a report of the above.

## Enforcement

Report concerns to the maintainer at the address in `Cargo.toml`'s `authors`
field, or via a private GitHub security advisory. Reports are read by the
maintainer only. Consequences run from a request to stop, through a temporary
ban, to a permanent one, depending on severity and repetition.

## Attribution

This document is intentionally short. It is compatible in spirit with the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which you may read if you want the long form.
